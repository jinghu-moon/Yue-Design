## Consumer migration note

- `@yue-ui/design-tokens`：把 `import '@yue-ui/design-tokens/components.css'` 改为按需选择——
  要 token 就仍然装 `@yue-ui/design-tokens/index.css`；确实要用原型期 `.btn` / `.field` 选择器时，
  显式装 `@yue-ui/design-tokens/implementations.css`。
- `YueTag`：`size=lg` 由 40px 变为 30px，默认形状由胶囊变为方形（需要胶囊时用 `shape="round"`）；
  禁用态透明度由 0.45 变为 0.38。若你在消费端覆盖过 `--tag-height-*` / `--tag-border-radius`，
  覆盖点仍然有效，但默认值不再与控件尺寸绑定。
- 覆盖 `--input-focus-ring-width` / `--input-focus-ring-offset` 的消费端：这两个 token 现在真的生效了
  （改动前它们被实现忽略）。
