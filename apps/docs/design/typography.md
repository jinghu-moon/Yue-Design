# 字体

字体首先服务于阅读和信息层级。Yue 的字体 Token 不要求消费方安装特定字体，但包内提供本地字体资产作为默认视觉基准，不依赖外部 CDN。

## 字体角色

| 角色 | Token | 用途 |
| --- | --- | --- |
| UI 字体 | `--font-ui` | 界面文字、表单和组件 |
| 等宽字体 | `--font-mono` | 代码、Token 名称和日志 |
| 数字字体 | `--font-number` | 需要稳定数字宽度的统计和数据 |

## 字阶和行高

当前字阶从 `--font-size-sm` 到 `--font-size-display`，行高从 `--line-height-sm` 到 `--line-height-display`。组件应优先使用自己的 Component Token 映射字阶，页面标题才直接使用基础字阶。

- 正文至少使用 `14px` 和正常行高；密集控件可以使用 `12px`，但不能承载长篇说明。
- 字重用于建立层级，不用颜色和粗体同时过度强调。
- 字间距默认保持 `0`；只有展示型标题或全大写短标签才考虑额外字距。
- 字体加载失败时必须回退到系统字体，不能因为字体资源失败导致布局不可用。
