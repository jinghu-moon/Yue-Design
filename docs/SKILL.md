# Yue Design Component Skill

The canonical component-development skill is:

[`.agent/skills/yue-component-design/SKILL.md`](../.agent/skills/yue-component-design/SKILL.md)

Use it for every new Yue component or component family. The detailed design, accessibility,
documentation, testing, and acceptance checklist is in:

[`.agent/skills/yue-component-design/references/acceptance-checklist.md`](../.agent/skills/yue-component-design/references/acceptance-checklist.md)

This replaces the archived project's component skill. The archived document is useful as
historical input, but its package names, Token prefix, install model, and some focus/overlay
rules do not describe the current Yue-Design repository.

For user-facing strings, language packs, locale adapters, RTL, or bilingual documentation, also
use [`.agent/skills/yue-i18n/SKILL.md`](../.agent/skills/yue-i18n/SKILL.md) and
[`docs/03-yue-i18n-roadmap.md`](./03-yue-i18n-roadmap.md).

The companion Skills are [Vue development](../.agent/skills/yue-vue-development/SKILL.md),
[testing](../.agent/skills/yue-testing/SKILL.md), [documentation](../.agent/skills/yue-docs/SKILL.md),
and [release](../.agent/skills/yue-release/SKILL.md).
