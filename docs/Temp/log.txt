Vuetify 用 --v-theme-primary: 24,103,192 存颜色，让 rgb(var(--v-theme-primary) / 0.5) 直接做 opacity 合成。Yue 用 color-mix()
实现了类似的效果（这个决策是对的），但 color-mix() 语法更冗长，且在某些需要用 JS 读取颜色值的场景不如 RGB 通道灵活。这个不是必须改，只是一

---                                                                                                                                      

具体改造建议                                                                                                                             

改动一：消灭双轨——明确 components/*.css 的职责                                                                                           

每个 components/*.css 文件分为两段：                                                                                                     

/* 1. Token 定义 — 进入 layer(components) */                                                                                             
@layer components {
  :root {                                                                                                                                
    --tag-height-sm: 20px;
    --tag-height-md: 24px;                                                                                                               
    /* ... */
    --tag-default-filled-background: var(--surface-component);                                                                           
    /* ... */
  }                                                                                                                                      
}
                                                                                                                                         
/* 2. CSS 规则 — 进入 layer(implementations) */
@layer implementations {                                                                                                                 
  .yue-tag {
    height: var(--tag-height-md);                                                                                                        
    background-color: var(--tag-default-filled-background);
    /* ... */                                                                                                                            
  }
}                                                                                                                                        

同时 index.css 直接引入每个文件：                                                                                                        

@layer primitives, semantics, components, implementations, demo;                                                                         

@import url('./primitives.css') layer(primitives);                                                                                       
@import url('./semantics.css') layer(semantics);
@import url('./components.css') layer(components);          /* 共享 geometry */                                                          
@import url('./components/button.css');                     /* 自带分层声明 */
@import url('./components/tag.css');                                                                                                     
@import url('./components/input.css');
                                                                                                                                         
这样每个组件的 token 和规则在同一个文件里，source of truth 唯一，和 TDesign 的 _var.less + _index.less 共存于同一组件目录的思路一致。

改动二：修复 package.json export

"./components.css": "./src/components.css"

改动三：断掉 semantics → components 前向引用

/* semantics.css — 改成在语义层自己定义，不依赖 components */
--list-row-background-hover: color-mix(
  in srgb,
  var(--text-primary) calc(var(--opacity-hover) * 100%),
  transparent
);

改动四：统一 --tag-border-radius 的定义

从 components.css 里删掉来自 prototype 的旧定义（var(--radius-full)），只在 components/tag.css 里保留正确的值，加注释：

/* 默认方角；round 形状通过 --tag-border-radius-round 实现。
   prototype (design-tokens-generic-v4) 里此 token 是 --radius-full，
   Yue Tag 的设计选择是 square-first，故在此显式覆盖。 */
--tag-border-radius: var(--radius-xs);   /* 4px */

改动五：input focus ring 要用自己的 token

/* form.css */
box-shadow: 0 0 0 var(--input-focus-ring-width)
            color-mix(in srgb, var(--input-border-color-focus) 24%, transparent);

改动六：禁用透明度统一

/* components/tag.css */
--tag-opacity-disabled: var(--opacity-disabled-content);

改动七（可选）：借鉴 TDesign 的 surface-invert-aware

/* semantics.css */
--surface-invert-aware: #fff;

[data-theme=dark] {
  --surface-invert-aware: transparent;   /* 暗色模式继承父背景 */
}

总结

Yue 的 token 架构主干是健康的：三层分离、color-mix() 状态变体、--control-* 几何抽象、@media (prefers-reduced-motion) 的语义 motion alias——这些和 TDesign 的思路高度一致，决策正确。

核心问题是 components/ 目录游离在主链路之外，造成了 source of truth 的分裂。这次 Tag bug 是这个缺陷的第一次显现，不会是最后一次。改动一到三是结构性修复，优先级最高；四到六是现有一致性债务；七是锦上添花。
